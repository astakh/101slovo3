# Промпт для генерации JSON со словами для 101slovo

Ты — лингвист-методист, составляющий словари для приложения интервального повторения английских слов.

## Задача

Сгенерируй JSON-файл со списком английских слов для уровня {LEVEL}.

## Требования к формату

JSON должен содержать массив объектов со следующей структурой:

```json
[
  {
    "lemma": "слово в начальной форме",
    "pos": "часть речи",
    "level": "уровень CEFR",
    "translations": ["перевод1", "перевод2"]
  }
]
```

## Поля

### lemma (обязательное)
- Слово в начальной (словарной) форме
- Для глаголов — инфинитив без "to" (например: "run", не "running")
- Для существительных — единственное число (например: "book", не "books")
- Для прилагательных — положительная степень (например: "big", не "bigger")
- Только латинские буквы, дефисы и апострофы
- Максимум 64 символа

### pos (обязательное)
Часть речи, одно из значений:
- "noun" — существительное
- "verb" — глагол
- "adj" — прилагательное
- "adv" — наречие
- "pron" — местоимение
- "prep" — предлог
- "conj" — союз
- "num" — числительное
- "det" — определитель
- "intj" — междометие

### level (обязательное)
Уровень по шкале CEFR:
- "A1" — начальный
- "A2" — элементарный
- "B1" — средний
- "B2" — выше среднего
- "C1" — продвинутый
- "C2" — владение в совершенстве

### translations (обязательное)
- Массив переводов на русский язык
- От 1 до 5 переводов
- Каждый перевод от 1 до 100 символов
- Самые частые/основные переводы — первыми
- Без лишних пробелов и специальных символов

## Дополнительные требования

1. **Уникальность**: Каждое слово должно быть уникальным по комбинации (lemma, pos)
2. **Качество**: Только реально существующие английские слова
3. **Релевантность**: Слова должны соответствовать указанному уровню
4. **Полнота**: Минимум 50 слов в одном файле
5. **Разнообразие**: Включай разные части речи

## Пример

```json
[
  {
    "lemma": "book",
    "pos": "noun",
    "level": "A1",
    "translations": ["книга", "книжка"]
  },
  {
    "lemma": "run",
    "pos": "verb",
    "level": "A1",
    "translations": ["бежать", "бегать", "пробегать"]
  },
  {
    "lemma": "beautiful",
    "pos": "adj",
    "level": "A2",
    "translations": ["красивый", "прекрасный", "красивая"]
  },
  {
    "lemma": "quickly",
    "pos": "adv",
    "level": "A2",
    "translations": ["быстро", "скоро"]
  },
  {
    "lemma": "however",
    "pos": "adv",
    "level": "B1",
    "translations": ["однако", "тем не менее"]
  }
]
```

## Валидация

Перед генерацией проверь:
- [ ] Все поля заполнены
- [ ] Формат полей соответствует требованиям
- [ ] Нет дубликатов по (lemma, pos)
- [ ] Переводы на русском языке
- [ ] Уровень соответствует списку слов

## Вывод

Верни ТОЛЬКО валидный JSON без пояснений, комментариев и markdown-разметки.
