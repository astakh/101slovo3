# Скрипты для работы со словами

Этот каталог содержит скрипты для генерации и импорта слов в базу данных 101slovo.

## Содержание

- `word_generation_prompt.md` - промпт для генерации JSON со словами
- `import_words.py` - скрипт импорта слов из JSON в базу данных
- `example_words.json` - пример JSON файла с 10 словами
- `words_a1_sample.json` - пример JSON файла с 55 словами уровня A1

## Быстрый старт

### Установка зависимостей для скриптов

```bash
cd scripts
pip install -r requirements.txt
```

### Использование

#### 1. Генерация слов

Используйте промпт из `word_generation_prompt.md` с любой LLM (GigaChat, ChatGPT, Claude и т.д.) для генерации JSON файла со словами.

**Пример запроса:**
```
Используя промпт из word_generation_prompt.md, сгенерируй 50 слов для уровня A1.
Верни только валидный JSON без пояснений.
```

Сохраните результат в файл, например `words_a1.json`.

#### 2. Импорт слов

Запустите скрипт импорта:

```bash
cd scripts
python import_words.py words_a1.json --dictionary-id 1
```

**Параметры:**
- `words_a1.json` - путь к JSON файлу со словами
- `--dictionary-id 1` - ID словаря в таблице `dictionaries` (по умолчанию 1)

**Примечание:** Скрипт автоматически читает `DATABASE_URL` из `backend/.env`, поэтому не требует установки всех зависимостей backend.

**Что делает скрипт:**
1. Читает JSON файл
2. Валидирует каждое слово (проверяет обязательные поля, форматы)
3. Вычисляет `lemma_key` (нормализованная форма леммы)
4. Проверяет уникальность по `(lemma_key, pos)`
5. Вставляет новые слова в таблицу `words`
6. Выводит статистику (добавлено/пропущено/ошибки)

### 3. Формат JSON

JSON должен содержать массив объектов:

```json
[
  {
    "lemma": "book",
    "pos": "noun",
    "level": "A1",
    "translations": ["книга", "книжка"]
  },
  {
    "lemma": "run",
    "pos": "verb",
    "level": "A1",
    "translations": ["бежать", "бегать"]
  }
]
```

**Обязательные поля:**
- `lemma` - слово в начальной форме (строка, 1-64 символа)
- `pos` - часть речи: noun, verb, adj, adv, pron, prep, conj, num, det, intj
- `level` - уровень CEFR: A1, A2, B1, B2, C1, C2
- `translations` - массив переводов на русский (1-5 элементов)

## Проверка уникальности

Скрипт проверяет уникальность по комбинации `(lemma_key, pos)`, где `lemma_key` - это нормализованная форма леммы (lowercase, NFC normalized).

**Примеры:**
- `book` (noun) и `book` (verb) - разные слова (разные pos)
- `Book` и `book` - одно слово (одинаковый lemma_key)
- `run` и `running` - разные слова (разные lemma)

## Пример использования

```bash
# 1. Перейти в папку scripts

# 2. Запустить импорт с примером
```

## Требования

- Python 3.12+
- Установленный пакет `psycopg` (можно установить отдельно: `pip install psycopg[binary]`)
- Настроенный файл `backend/.env` с переменной `DATABASE_URL`
- Таблица `dictionaries` должна содержать хотя бы одну запись

**Важно:** Скрипт автономный и не требует установки всех зависимостей backend. Он читает `DATABASE_URL` напрямую из `backend/.env`.

## Проверка словаря

Перед импортом убедитесь, что словарь существует:

```sql
SELECT id, code, name FROM dictionaries;
```

Если словарь не создан, создайте его:

```sql
INSERT INTO dictionaries (code, name, description) 
VALUES ('general', 'General English', 'Общий словарь английских слов');
```

## Troubleshooting

**Ошибка: "Файл не найден"**
- Убедитесь, что путь к JSON файлу правильный
- Проверьте текущую директорию

**Ошибка: "Неверный dictionary-id"**
- Проверьте, что словарь с таким ID существует в таблице `dictionaries`

**Ошибка: "Отсутствует обязательное поле"**
- Проверьте формат JSON файла
- Убедитесь, что все слова содержат поля: lemma, pos, level, translations

**Все слова пропущены как дубликаты**
- Слова уже есть в базе данных
- Проверьте таблицу `words`: `SELECT COUNT(*) FROM words;`
