# Страница урока (Lesson)

## Описание

Страница урока (`/lesson`) — это основное рабочее пространство пользователя, где происходит изучение слов через перевод предложений.

## Как это работает

### 1. Загрузка упражнения

При переходе на `/lesson` загружается первое упражнение урока:
- Английское предложение
- Целевые слова (выделены жёлтым)
- Эталонный перевод (скрыт до проверки)

### 2. Ввод перевода

Пользователь вводит перевод предложения на русский язык в текстовое поле.

### 3. Проверка перевода

При нажатии "Проверить" происходит:
- Отправка перевода на сервер (`POST /lesson/evaluate`)
- Получение результата проверки для каждого целевого слова
- Отображение результата (правильно/неправильно)

### 4. Результат

После проверки показывается:
- Статус (правильно/неправильно)
- Эталонный перевод
- Результаты по каждому целевому слову
- Кнопка "Следующее упражнение"

### 5. Кнопка "Не знаю"

Если пользователь не знает перевод, он может нажать "Не знаю":
- Все целевые слова помечаются как неправильные
- Показывается эталонный перевод
- Пользователь может перейти к следующему упражнению

## Структура страницы

```
Lesson.tsx
├── Header
│   ├── Кнопка "Назад" (→ Dashboard)
│   ├── Название урока
│   └── Прогресс (упражнение X / Y)
├── Exercise Card
│   ├── Sentence (английское предложение)
│   ├── Target Words (целевые слова)
│   ├── User Input (текстовое поле)
│   ├── Buttons (Не знаю / Проверить)
│   └── Result (после проверки)
│       ├── Status (правильно/неправильно)
│       ├── Reference Translation
│       ├── Word Results
│       └── Next Button
```

## API интеграция

### Текущая реализация (заглушка)

Сейчас используется имитация проверки:
```typescript
const correct = userTranslation.toLowerCase().includes('достиг') && 
                userTranslation.toLowerCase().includes('цел');
```

### Подключение реального API

В `src/pages/Lesson.tsx` замените заглушку на реальный вызов:

```typescript
const handleSubmit = async () => {
  setIsLoading(true);
  try {
    const response = await fetch('http://localhost:8000/lesson/evaluate', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${localStorage.getItem('access_token')}`,
      },
      body: JSON.stringify({
        exercise_id: currentExercise.id,
        translation: userTranslation,
      }),
    });

    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.detail || 'Ошибка проверки');
    }

    const data = await response.json();
    setResult(data);
    setShowResult(true);
  } catch (error) {
    console.error('Ошибка проверки:', error);
  } finally {
    setIsLoading(false);
  }
};
```

## Состояние

Компонент использует локальное состояние:
- `userTranslation` — ввод пользователя
- `showResult` — показывать ли результат
- `isCorrect` — правильный ли перевод
- `isLoading` — состояние загрузки

## Навигация

- **Кнопка "Назад"** — возврат на Dashboard
- **Кнопка "Следующее упражнение"** — переход к следующему упражнению
- **Кнопка "Не знаю"** — пропуск упражнения

## Тестирование

1. Перейдите на `/lesson`
2. Увидите английское предложение с целевыми словами
3. Введите перевод
4. Нажмите "Проверить"
5. Увидите результат проверки
6. Нажмите "Следующее упражнение"
7. Или нажмите "Не знаю" для пропуска
